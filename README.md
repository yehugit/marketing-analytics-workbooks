# Companion Workbooks: Marketing Analytics in Excel

This repository holds the Excel workbooks used in the Excel Labs of *Marketing Analytics in Excel* by Ye Hu.

**Readers: download the workbooks from the book's download page, https://github.com/yehugit/marketing-analytics-workbooks/, not from the file list below.** The download page gives one zip file per chapter.

## What is here

    workbooks/                  workbooks for each chapter's labs
    docs/                       the download page (published with GitHub Pages)
    CHANGELOG.md                workbook versions and the book printings they match
    ERRATA.md                   corrections to the book and the workbooks
    LICENSE.md                  terms of use

## Opening the files

Extract the zip file before opening a workbook; Excel opens files inside a zip as read-only. If Excel shows a yellow Protected View bar, click Enable Editing. The labs were written in Excel for Microsoft 365 on Windows. Nearly everything works the same on a Mac. Excel on the web, on tablets, and on Chromebooks lacks features some chapters need, including Solver.

## Instructors

Completed solution workbooks and answers to the end-of-chapter exercises are not in this repository. Instructors who adopt the book can request them at INSTRUCTOR-CONTACT.

## Reporting a problem

If a value in your worksheet does not match a lab's check table and you have followed the steps exactly, please open an issue on this repository with the chapter, lab number, step, and the value you obtained. Confirmed problems are listed in ERRATA.md.
