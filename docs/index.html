Before you start

  1. Extract the zip file (on Windows, right-click it and choose Extract All). Excel opens files inside a zip as read-only.
  2. If Excel shows a yellow Protected View bar, click Enable Editing.
  3. Keep an untouched copy of each workbook. Several labs ask you to start again from a fresh copy.

The labs were written in Excel for Microsoft 365 on Windows. Nearly everything works the same on a Mac, though some menus and shortcuts differ. Excel on the web, on tablets, and on Chromebooks lacks features some chapters need, including Solver.

Corrections

If your results do not match a lab's check table after following the steps exactly, see the errata. To report a new problem, open an issue with the chapter, lab number, step, and the value you obtained.
